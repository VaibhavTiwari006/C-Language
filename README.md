# C Language Practice

A topic-wise collection of C programs created while learning programming fundamentals and problem solving.

## Topics

- Basics
- Arrays
- Strings

## Repository structure

```text
C-Language/
├── Basics/
├── Array/
└── String/
```

## Run locally

Compile a program with GCC:

```bash
gcc path/to/program.c -o program
./program
```

On Windows, run the generated `program.exe`.

## Purpose

This repository documents my progress in C, with an emphasis on understanding core syntax, memory-oriented programming, arrays, strings, and fundamental algorithms.
